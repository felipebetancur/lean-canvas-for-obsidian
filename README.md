# 🧠 cerebro-emprendedor (Versión Free) — Sistema de control para emprendedores en Obsidian

Una suite ágil y adaptada para Obsidian, diseñada para ayudarte a mapear tu modelo de negocio tecnológico y liberar tu mente en el día a día utilizando archivos markdown, canvas y notas interconectadas.

Esta herramienta está basada en las metodologías Lean Canvas de Ash Maurya y en los marcos de transferencia tecnológica para proyectos de base científica.

## 🚀 Requisitos e instalación

1. Descarga este repositorio desde GitHub en formato `.zip` y descomprímelo.
2. Asegúrate de tener instalado **Obsidian** ([https://obsidian.md](https://obsidian.md)).
3. Abre Obsidian, selecciona **"Abrir una carpeta como bóveda"** (*Open folder as vault*) y elige la carpeta descomprimida `cerebro-emprendedor`.
4. El sistema se abrirá automáticamente mostrando este panel de control.

---

## 🧠 Cómo utilizar el Ecosistema

### 1. Diseña tu estrategia comercial (El Lean Canvas)
Abre la carpeta `00_Lean_Canvas` y ejecuta el archivo `lienzo_principal.canvas`. Puedes escribir directamente en las tarjetas visuales o editar las notas individuales de la subcarpeta `Secciones`. Conecta tus hipótesis utilizando los enlaces internos `[[ ]]`.

### 2. Para proyectos de ciencia e ingeniería (Science Lean Canvas)
Si estás desarrollando tecnologías complejas o *DeepTech*, utiliza el lienzo dentro de `00_Science_Lean_Canvas`. Te ayudará a estructurar aspectos como propiedad intelectual, validación regulatoria y barreras de entrada técnicas junto con el mercado objetivo.

### 3. Ejecuta sin perder el enfoque (Nota diaria)
Configura el plugin nativo *Notas Diarias* de Obsidian para usar el molde alojado en `Plantillas/plantilla_nota_diaria.md`. Cada mañana, usa la sección de **Descarga Mental** para vaciar tu mente y define la **única prioridad del día** que haga avanzar tu negocio.
